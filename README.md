# WhiteNoise

An ambient sound machine for OVOS - white/brown noise, rain, ocean waves, fan noise, looped for sleep or focus. A surprisingly common voice-assistant feature (Alexa/Google both have it) that's missing from the OVOS ecosystem (checked before starting). Needs a small library of loopable ambient tracks, sourced the same way as ovos-skill-sound-like's bundled sounds (CC0-verified).

> **This is a skeleton only - not implemented yet.** Repo, structure,
> and design notes are in place; the actual skill logic hasn't been
> written. See "Design notes" in [DEVELOPMENT.md](DEVELOPMENT.md).

## Why this exists

Nothing like this exists in the OVOS ecosystem yet (checked before starting). Sourcing note: needs genuinely loopable tracks (seamless start/end), which is a stricter requirement than the short one-shot clips ovos-skill-sound-like uses - worth extra care when picking sources.

## Planned usage (not yet functional)
```
"play white noise"
"play rain sounds"
"stop the ambient sound"
```
